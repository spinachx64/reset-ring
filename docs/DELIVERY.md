# 交付状态

源码、Mac Bridge、原厂应用集成脚本、Flash 恢复脚本、LaunchAgent 安装脚本、自动测试和桌面 LVGL 预览均已写入项目。已将用户选定的第 3 版「柔和层次」刷入串口连接的 StopWatch，Bridge 已安装并运行。

实物反馈已处理：

1. 右键切换保留原厂 GoNext 映射。
2. 左键刷新加入轻振动与百分比淡化反馈，额度没有变化时保留原数字。
3. 主页第一项为 Codex StopWatch，使用独立 Codex 图标；点按图标进入。其他原厂应用保留。
4. BMI270 到面板的方向增加 180° 校正，并根据横向实物反馈反转 X 轴符号。按用户最新选择启用任意角度连续转正，平放或尚无稳定重力时保持最近朝向。
5. BLE 接收队列带实际单调时钟接收时间，返回表盘不会把在主页收到的旧包误当成刚收到。

可重复的验证步骤与已验证/待实物复核项见 [VALIDATION.md](VALIDATION.md)。当前尚未声称完成长时间续航、真实服务端跨周期或全部物理姿态的验收。

最新界面采用第 3 版的上下比例、低饱和灰绿/暗金、细环和淡底色层次；毫秒行已移除，内部单调计时保留。设计参数见 [DESIGN.md](DESIGN.md)，生产 LVGL 渲染图见 [selected-watchface.png](selected-watchface.png)。
