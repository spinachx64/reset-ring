# 选定表盘：03 / 柔和层次

用户在本地 Web 预览中选择第 3 版，并要求移除毫秒、降低刺眼程度。本次选择覆盖原始 v1.0 spec 中的毫秒行、亮绿/亮琥珀和三行布局要求；原始 spec 保留作历史记录。

- 布局按逻辑画布 466×466 居中，实际设备 468×466。中央内容随重力任意角度连续转正，外环固定。
- 百分比位于上方，数字 68px、百分号 44px，基线对齐。主倒计时位于下方，5H 为 68px、Weekly 为 49px，固定数字格宽避免跳动。底部仅有一条很淡的短横线。
- 删除毫秒显示与对应字体资源；保留内部毫秒单调时钟精度，避免掉帧累积计时误差。
- 余量环半径 206px、宽 5px，仍以 12 点开始、顺时针显示一个连续段。很淡的同弧晕光不形成第二段亮弧。
- 颜色参照 Web 预览默认 75% 亮度：5H `#5E7667`，Weekly `#807257`，主时间 `#899086`。降低像素亮度，不修改原厂其他应用的全局屏幕亮度。
- 底盘使用很暗的灰绿/灰金径向色阶，低亮填充近似预览层次，无需新增全屏位图缓冲或开启复杂渐变渲染器。
- 额度变化、模式过渡、确认重置、左键反馈与单秒翻数保留。无毫秒内容时，空闲帧不再因其数字变化而使显示失效重绘。
- IMU 轴向校准、按键、主页入口、NVS、BLE 及数据真实性逻辑沿用已联调版本。

验证用真实生产 LVGL 代码生成 5H、Weekly、90°、未知、100% 和 0% 快照，检查比例、裁切与空值展示。Web 预览与实物 AMOLED 在亮度和渐变细节上仍有显示介质差异。

## 任意角度转正

根据用户后续选择，默认由四向吸附改为连续重力转正。加速度采样周期 25ms，使用约 70ms 时间常数的低通滤波与 1.5° 输出死区，旋转补间缩短到 120ms。平放锁定使用约 16° / 22° 的进入/恢复滞回；加速度模长异常时保持最近朝向。

任意方向都用 `remainder(target-current, 360)` 取最短旋转量，修正多圈转动后的方向错误。加速度计无法在几乎平放时确定屏幕内的重力朝向，因而此时保留上一次方向。
